# 選べる数学カード「無理数トランプ」

『数学のとびら』（日本書籍、1984）所収「無理数トランプ」の仕組み――「同じ数学的対象を、違う表し方にしたカード同士をそろえる」――を、6つの単元に広げた単体HTMLのカードゲームアプリです。

起点は、清水正典先生が新卒時代に先輩から教わった実践（班ごとにカードを作らせ、遊びながら√計算を定着させた授業）です。カードの数値例は本アプリのために新たに作成し、全組をプログラムで検算しています。

## セット（全6セット・選べる）
| セット | 学年 | 組数 | 4つの表現 |
|---|---|---|---|
| 平方根 | 中3 | 15組＋√0ジョーカー | 簡単な形／√n／√(a²×b)／√どうしの積 |
| 割合 | 中1 | 16組 | 分数／小数／百分率／歩合 |
| 累乗 | 中1〜中3 | 16組 | 数／累乗A／累乗B／かけ算の形 |
| 一次方程式 | 中1 | 14組 | 方程式／移項した式／解／検算式 |
| 因数分解 | 中3 | 15組 | 展開形／因数分解形／解／x＝10の値 |
| 一次関数 | 中2 | 13組 | 式／表／グラフ／言葉（傾き・切片） |

## モード
- 神経衰弱（ソロ／CPU対戦、組数は難易度で選択）
- ババぬき（あなた＋CPU 3人。平方根は√0ジョーカー、他はジジぬき方式）
- フラッシュ練習（見本と同じ組の3枚をすばやくタップ、+2秒ペナルティ式）
- 値の一覧表（いつでも参照できる足場かけ）
- 印刷用カードシート（A4・300dpi画像、縦9cm×横7cm、切り取り線つき、全セット分）

ベスト記録は端末内（localStorage）に保存されます。効果音は Web Audio の合成音です。

## ファイル
- `index.html` ― アプリ本体（単体・自己完結）
- `template.html` / `data.js` / `app-logic.js` ― ソース（`node build-app.js` で結合）
- `verify.js` ― データ整合＋動作の検証スクリプト（全600項目）
- `set-research.md` ― セット設計と検算の調査記録
