# AI先生 試作版（Ollamaローカル接続）

このフォルダーは、Math Quartet本体を変更せずにAI先生の動作を試すための独立した試作です。

## できること

- 学年を選び、数学の質問を日本語で入力
- 中学生向けの順序立てた解説を生成
- Ollamaのローカルモデル `qwen3.5:4b` を利用
- 質問と回答は、このPC上のPythonサーバーとOllamaの間で処理

## 必要なもの

- Windows / Python 3
- Ollama
- Ollamaモデル `qwen3.5:4b`

## 起動手順（Windows PowerShell）

1. Ollamaがインストールされ、モデルがあることを確認します。

```powershell
ollama list
```

一覧に `qwen3.5:4b` がなければ、次を実行します。

```powershell
ollama pull qwen3.5:4b
```

2. このフォルダー（`ai-teacher`）に移動し、サーバーを起動します。

```powershell
py server.py
```

3. ブラウザーで次を開きます。

```text
http://127.0.0.1:8765
```

4. 終了するときは、PowerShellで `Ctrl+C` を押します。

## 安全と設計

- Pythonサーバーは `127.0.0.1` にだけ待ち受けます。LANやインターネットには公開しません。
- APIキーは不要です。
- 既存の `index.html`、ゲームロジック、学習記録には変更を加えません。
- ブラウザーからは同じPC上のPythonサーバーだけに接続し、PythonサーバーがOllamaへ問い合わせます。
- 質問欄には氏名、住所、学校名などの個人情報を入力しないでください。
- AIの説明は誤る場合があります。教科書や先生の説明と照らし合わせてください。

## 現時点の範囲

これは独立した動作確認用の試作です。Math Quartetのゲーム画面への組み込み、間違えたカード情報の自動連携、学習履歴の保存はまだ行いません。動作確認後、既存アプリへの安全な接続方法を検討します。
